# PACATIS Web

parent app prototype, organized for the next backend/API phase.

## Structure

- `src/data/` — demo/seed data and browser persistence
- `src/analytics/` — deterministic care analytics and evidence calculations
- `src/components/` — reusable UI and modal components
- `src/pages/` — product screens
- `src/App.jsx` — application shell and navigation
- `src/main.jsx` — browser entry point

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
